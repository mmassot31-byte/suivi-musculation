# Catalogue V2 — propositions explicites

Les noms Volume, Tonnage, Régularité, Secrets et Exploits reprennent le PDF du 9 novembre 2026. Les identifiants sont conservés.

Les **48 noms Performance ci-dessous sont de nouvelles propositions**, après recherche dans les sources textuelles du dépôt ; ils ne constituent pas un accord historique retrouvé. Les raretés Volume conservent les fondations. Les autres affectations de rareté sont proposées : progression par palier, deux paliers par rareté pour le Tonnage, raretés plus élevées pour les exploits durables. Aucun seuil métier n’a été ajusté.

# Formulaire des objectifs

La refonte du tableau de bord prolonge ce formulaire en trois étapes. Les versions 1, 2 et 3 restent lisibles ; les nouveaux objectifs utilisent la version 4. Les modifications gardent désormais le même identifiant, avec une configuration par période et un journal de paramètres.

Voir [le modèle et ses vérifications](long-term-goals.md) pour les règles actuelles, les limites de validation et la récurrence calendaire.

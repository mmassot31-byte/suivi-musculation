# Aperçus iPhone et interface sociale

Les trois maquettes de `elan-apercus-iphone-codex.zip` ont été comparées au kit fonctionnel Amis / Défis / Badges. Leur composition mobile est prioritaire : segments Amis / Défis / Classements, cartes d’invitations, actions tactiles, jauges, favoris et prochain palier.

Les améliorations de présentation antérieures sont conservées (profil compact, SVG, anciens défis, cache actualisé), raccordées aux véritables amitiés, objectifs et badges serveur. Aucun faux score ni barre système d’iPhone n’est intégré.

Le cache v25-community recharge les ressources à l’installation et revalide HTTP, sans recharger une séance en cours. Voir [le rapport fonctionnel et les migrations activées](COMMUNITY-SETUP.md).

Les tests utilisent exclusivement des comptes fictifs. Les captures de test ne représentent pas des données de production ; Safari/iPhone physique et le parcours avec deux comptes authentifiés restent des validations séparées.

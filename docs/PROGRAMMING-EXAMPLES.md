# Programmes effectivement générés

Générés par `npm run examples` à partir de `data.js`, semaine du 2 novembre 2026. Ce sont les modèles initiaux du dépôt, pas les données privées du téléphone. Hypothèses : repos personnels conservés (90 s), échauffement général 6 min, préparation selon demande avec 60 s de repos, installation 60 s, transitions entre postes 90 s, 3,5 s/répétition et marge 3 min. La borne haute de la plage estimée est la contrainte de temps. Les répétitions reflètent les habitudes comparables ; aucune charge nouvelle n’est inventée.

Les choix sont reproductibles, sans API d’IA. Les repères restent souples et partiellement extrapolés. Les machines nouvelles ne sont pas supposées disponibles. Les articles PubMed n’ont pas pu être consultés (proxy HTTP 403) : voir `PROGRAMMING.md`.

## Analyse des programmes obtenus

- À quatre séances, les Upper conservent poussée, tirages horizontal/vertical et travail latéral ; les bras peuvent avoir surtout une exposition secondaire. Ce compromis est visible plutôt que compensé par des accessoires supplémentaires hors budget. Plusieurs repères restent non atteints ; le moteur ne prétend pas garantir des gains insuffisants ou maximaux.
- Les Jambes A/B peuvent partager leurs exercices : la stabilité est préférée à une variation arbitraire. Une charnière de hanche peut remplacer un mouvement de dos non classé pour couvrir une fonction explicite, avec charge à déterminer. Les modèles originaux restent intacts.
- Des créneaux différents produisent des contenus différents. Une redistribution locale peut transférer une série entre deux occurrences comparables, sans changer le volume total, si les verrous et le temps le permettent ; elle n’est pas imposée sur des jours rapprochés.
- Le catalogue restreint suffit à construire une variante haltères/poids du corps quand assez de nouvelles substitutions sont autorisées. Si cette permission est trop faible, l’interface affiche l’incompatibilité au lieu d’inventer une machine.
- Le groupe verrouillé 3/2 reste A–B–A–B–A. La disponibilité de deux postes est explicitement incertaine. Un verrou n’est pas levé parce qu’une autre combinaison aurait un meilleur score de volume.
- Une séance manquée reste une occurrence distincte ; les ajustements proposés dans le futur sont limités et demandent confirmation. Aucun entraînement réalisé n’est recopié ou doublé.
- Les exemples refusés montrent les contraintes à revoir, pas la preuve qu’aucune solution humaine n’existe. Les bornes et catégories de fatigue sont des choix pratiques, à calibrer avec l’expérience.
